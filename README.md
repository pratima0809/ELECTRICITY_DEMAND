# Electricity Demand Forecasting System

A comprehensive Streamlit-based web application to forecast electricity demand using Machine Learning models.

## 1. Local Deployment

```bash
pip install -r requirements.txt
streamlit run app.py
```

## 2. Streamlit Community Cloud Deployment

* Upload project to GitHub
* Login to Streamlit Community Cloud
* Connect GitHub repository
* Select `app.py`
* Deploy
